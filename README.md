# Poker Helper Android

Офлайн Android-приложение для учебного анализа раздач Texas Hold'em.

## Что есть

- выбор количества игроков и позиции;
- ввод Hero, флопа, терна, ривера через всплывающее окно выбора карт;
- ввод известных карт оппонентов;
- загрузка скрина стола как фона/подсказки для ручного ввода карт;
- расчёт вероятности победы/ничьей методом Monte Carlo;
- расчёт аутов;
- простая рекомендация: фолд / колл / бет / рейз;
- полностью офлайн, интернет не требуется.

## Как получить APK через GitHub

1. Создай новый репозиторий на GitHub, например `poker-helper-android`.
2. Загрузи все файлы из этой папки в репозиторий.
3. Открой вкладку **Actions**.
4. Выбери workflow **Build Android APK**.
5. Нажми **Run workflow**.
6. После сборки открой завершённый запуск и скачай файл из блока **Artifacts**: `PokerHelper-debug-apk`.
7. Внутри будет `PokerHelper-debug.apk`.

## Установка на Android

1. Скачай APK на телефон.
2. Открой файл.
3. Разреши установку из неизвестных источников, если Android попросит.
4. Установи приложение.

## Важно

Приложение предназначено для обучения и анализа раздач. Не используйте его там, где правила площадки запрещают подсказки в реальном времени.
